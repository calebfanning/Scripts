# Introduction
  Fiji (https://pmc.ncbi.nlm.nih.gov/articles/PMC3855844/), QuPath (https://www.nature.com/articles/s41598-017-17204-5), and other associated tools are open-source technologies within the neuroscience field that provide analysis of brain slices in rodents. Despite numerous publications utilizing these tools, there is no standard process for an integrated multi-program installation pipeline from scratch.
  Aligning Big Brain Atlases (ABBA) enables researchers to overlay brain atlases by superimposing an atlas onto the specified model in Fiji (https://doi.org/10.1016/j.celrep.2025.115876). Manual affine registration in ABBA is time-consuming and prone to human errors, especially in large sets of data with hundreds of slices. DeepSlice is an AI-integrated tool within ABBA to help automate this calibration (https://www.nature.com/articles/s41467-023-41645-4). However, because its underlying model is trained on whole sections rather than inferring missing sections, it struggles to accurately register imperfect brain images. Severe tissue deformity, angled images, and human errors in the laboratory (e.g., imaging overlapping sections when operating Keyence microscopes) can frequently cause DeepSlice to malfunction. Although DeepSlice performs well with practically complete rat brain datasets that encompass the entire coronal section, it should be viewed as a tool to streamline the workflow rather than a direct substitute for manual affine registration. To prevent image downsampling and ensure data privacy, we recommend using local DeepSlice registration instead of API-based DeepSlice for accurate processing of datasets. An alternative approach to DeepSlice is Elastix, but it requires manual affine registration to all brain slices (https://ieeexplore.ieee.org/document/5338015).
  Even with initial success in ABBA registration, researchers must then transfer the mapping, comprising a set of coordinates within the image, from ABBA into QuPath for analysis (e.g., counting labeled cells, quantifying fiber density). Researchers have faced difficulties exporting regions of interest (ROI) back into QuPath; QuPath failed to read the mapping, meaning it could not produce ROIs within the brain images, preventing further analysis. Manual analysis of brain images in QuPath can be tedious, and researchers have had issues with some analysis evaluations. While existing research has addressed and facilitated some analysis (https://pmc.ncbi.nlm.nih.gov/articles/PMC9901451/#s2), many still require additional scripts to streamline the processes.
  To address these limitations, we have developed software pipelines to simplify workflow and resolve these problems. First, we have outlined a procedure that uses a single script, which will install Fiji (with required plugins), QuPath (including extensions), and Elastix in a designated folder. While existing instructions for installing local DeepSlice registration are available, we devised a clearer procedure. Second, we developed an automated workflow for batch registration and analysis of Bio-Formats/OMERO compatible rat brain images using ABBA and QuPath. Third, to resolve issues regarding QuPath analysis, we formulated Python and Groovy scripts to optimize the analysis. Specifically, to merge several QuPath projects while still saving the mapping, we developed a Python-based automation pipeline that automates the transfer of ABBA-generated registration coordinates (.json/.zip) and Atlas Ontology files (e.g., Waxholm Rat Brain Atlas). Furthermore, to ensure that ROI mappings were not collapsing to the root section in QuPath, we developed custom Groovy scripts within QuPath to automate cell detection and quantification, extracting and converting QuPath cell-detection metadata into tab-delimited formats.
